# The Geometry Calculator!
***
This project can calculate the area, perimeter, and a few other things with 4 different shapes, a circle, rectangle, square, and a triangle. It stores those measurement calculations, so you can view or compare them later! The best thing is, it does all of the math for you! All you have to do is list the length, width, or radius! In conclusion... don't take my word for it, go test it for yourself! It surely works great, and if you come across any annoying errors, please relay it to me!

## How to use The Geometry Calculator!
***
1. Run the code
2. choose from the list of actions, but i'd recommend actually creating a shape or two first, then you can do the other things
3. once you create a shape or more, then you can look at the measurements, as well as compare measurements to other shapes
4. If you enter the wrong thing, it'll take you straight back to the main menu!
5. Besides that, it should be simple and easy to use.
You don't have to install anything, congrats! You stumbled across a simple code!

## List of key features!
***
1. This program lists you the measurements of any shape that is available for data, such as a circle, rectangle, square, or triangle.
2. This also allows you to compare the perimeter and area of any 2 shapes
3. You can also sort all shapes from smallest area to biggest area, to compare even more!
4. Finally, you can look at the math behind the calculation of shape measurements

## Installation instructions!
***
Nothing you need to install unless you don't have python on your computer!
